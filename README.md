# huhaiwei.github.io

Personal site for Haiwei Hu, served at <https://huhaiwei.github.io>. It's a small hand-rolled Jekyll site that started out as a fork of [al-folio](https://github.com/alshedivat/al-folio). Almost all of the theme has since been removed.

## Layout

| Path | What it is |
| --- | --- |
| `index.md` | Home / about page |
| `_pages/` | Tool pages: Biloxi dictionary, Ka'apor FST, K'iche' FST, 404 |
| `_layouts/default.html` | The single page layout (header, nav, footer) |
| `assets/css/style.css` | All styling |
| `assets/json/` | Data loaded by the tool pages |
| `_scripts/biloxi_extract.py` | Generates `assets/json/biloxi_dictionary.json` (not part of the build) |

`_pages/kaapor-fst-rebuilt.html` is generated by `build_jekyll.py`, which lives outside this repo. Edit the generator, not the page.

## Running locally

Open the repo in the devcontainer (VS Code → "Reopen in Container"). It runs `bin/entry_point.sh` on attach, and that serves the site at <http://localhost:8080> with live reload.

Without the container:

```sh
bundle install
bundle exec jekyll serve
```

## Deploying

Every push to `main` triggers `.github/workflows/deploy.yml`. The workflow builds the site and pushes `_site/` to the `gh-pages` branch, which GitHub Pages serves.

## Updating the CV

The CV page is currently hidden. To bring it back, add a `cv.md` with `permalink: /cv/` that links a PDF in `assets/pdf/`, then add a "cv" link to the nav in `_layouts/default.html` and to the links list in `index.md`.
